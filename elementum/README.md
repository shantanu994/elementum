# Elementum

> A clean, responsive React landing page built with modular components.

Live demo: https://elementum-sigma-six.vercel.app/

## Features

- Responsive layout with a hero, services, testimonials, newsletter, and footer.
- Modular component structure in src/components/ for easy customization.

## Tech Stack

- React
- Vite / Create React App (project scaffold)
- CSS modules / plain CSS for styling

## Live Demo

View the deployed site: https://elementum-sigma-six.vercel.app/

## Quick Start

1. Install dependencies

```bash
npm install
```

2. Start the development server

```bash
npm start
```

3. Build for production

```bash
npm run build
```

## Project Structure

- `public/` — static HTML and assets
- `src/` — app source
  - `App.js` — root component
  - `index.js` — app entry
  - `components/` — reusable UI components (Hero, Navbar, Services, Testimonials, Newsletter, Footer, About)

## Deployment

This project is deployed on Vercel: https://elementum-sigma-six.vercel.app/
